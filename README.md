# 3207FM2048.com

Static property website for 3207 FM 2048 in Boyd, Texas, presented by Jennifer Lewis, REALTOR®, The Lewis Team, and AB Attorney Broker Services.

## Publish with Netlify

Connect this repository in Netlify. No build command is needed. Set the publish directory to the repository root.

## Replace the photo placeholders

Add property photographs to the `assets` folder. Replace a placeholder element in `index.html` with an image such as:

```html
<img src="assets/exterior.jpg" alt="Front exterior of 3207 FM 2048">
```

Keep filenames lowercase and avoid spaces.
